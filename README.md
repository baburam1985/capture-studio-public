# Capture Studio — Screenshots & PDF

Public privacy policy and documentation for the Capture Studio Chrome extension.

- [Privacy policy](https://baburam1985.github.io/capture-studio-public/privacy/)
- [Read the policy on GitHub](PRIVACY.md)
- [Chrome Web Store listing](https://chromewebstore.google.com/detail/lhclhigfdanlpmkjholjladalldhoacb)

This repository contains public policy pages only. The extension source and user captures are not included.

## Hosting

GitHub Pages publishes the root folder of the `main` branch. The policy is at `privacy/index.html`; `PRIVACY.md` provides a readable fallback if Pages is temporarily unavailable. Keep these two policy copies aligned when data handling changes.
